Wordly Dictionary SPA
This project is a Single Page Application (SPA) that allows users to search for word definitions using a public dictionary API. The application fetches data without reloading the page and dynamically displays definitions, parts of speech, example usage, synonyms, and pronunciation audio.
JavaScript is used to handle form submission, fetch data from the API, update the DOM, and manage user interactions. The app also includes error handling for invalid searches, a light/dark theme toggle, and the ability to save favorite words using localStorage.
